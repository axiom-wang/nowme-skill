# 设计思路：club-newbie-sticker（糖果贴纸本）

> 虚构人物：小满，大一新闻传播，话剧社新成员，会用五种方言说“你吃了没”。人物与细节均为虚构。

## 想给人的感觉
一个刚报到、有点闹腾、很好认识的新人。像一本贴满贴纸的手账封面，可以上手玩。

## 核心视觉
首屏超大的名字 **“小满”**（得意黑，粉色错位投影），周围四张**可以拖动的贴纸**：蓝色圆贴纸写着最让人记住的细节“会用五种方言说‘你吃了没’”，另外几张是想尝试的事和最近的沉迷。社团墙要“被记住”，所以首屏就是“这个人”本身。

## 区块安排（data-nm-id）
| 区块 | 内容 | 为什么 |
| --- | --- | --- |
| `hero` | 跑马灯“新人报到” + 名字 + 四张贴纸 + 身份标签（新成员 / 大一 / 新闻传播） | 新成员先分新老；显示年级和专业是社团墙的默认边界 |
| `detail` | 方言卡：点一下换一种方言（5 种） | 把“让人记住的细节”变成能玩的东西，也是天然的话题 |
| `want-to-try` | 三张翻面卡：正面是想尝试的事，背面是为什么 | 想尝试的事是社团墙“生成前必须有”的一项 |
| `hobbies` | 社团之外的三个爱好，每个配一个 SVG 小图标 | 给别人找话头 |
| `say-hi` | 对话气泡 + 撒花按钮 | 引导去用平台的“想聊这个”；按钮只撒花，明确写了不会联系到人 |

## 用到的 Kit
`nm-theme-candy`、`nm-marquee`、`nm-sticker`（`--round`、`--burst`）+ `data-nm-drag`、`nm-float` / `nm-wiggle`、`data-nm-cycle`、`nm-flip` + `data-nm-flip`、`nm-speech`、`data-nm-confetti`、`nm-bg-dots`、`nm-chip`、`nm-reveal` + `data-nm-stagger`。字体：得意黑 400（标题，`--nm-display-weight: 400`，避免浏览器伪粗体）+ 霞鹜文楷 400（正文），西文 Space Grotesk 700。

## 动效（lively）
跑马灯、贴纸漂浮与摇摆、撒花、卡片切换的弹出都来自 Kit；减少动效时跑马灯与贴纸静止、撒花不触发，内容完整。

## 借鉴时注意
- 方言内容全部写在 HTML 里（`data-nm-cycle` 的子元素），不用脚本拼字，字体子集不会漏字。
- 贴纸不要太大：可拖动的元素会接管触摸，太大会让手机上很难滚动页面。
- “五种方言”这种细节必须是主人自己说的；没有这么好玩的细节时，宁可用一个普通但具体的细节，也不要编。
