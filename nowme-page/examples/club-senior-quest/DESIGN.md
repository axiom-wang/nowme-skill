# 设计思路：club-senior-quest（像素 RPG 角色卡）

> 虚构人物：周一鸣，大四软件工程，桌游社第三年的老成员，社团里的“规则书本人”。人物与细节均为虚构；提到的桌游是真实存在的游戏。

## 想给人的感觉
老成员不是来“求关注”的，而是**新人可以来找的人**。把他做成游戏里的引导 NPC：亲切、可靠、有点中二。

## 核心视觉
首屏一张**像素角色卡**：16×16 的像素头像、名字、职业“社团里的规则书本人”，下面一条按真实年资画的方块条（3/4 年），再下面是 RPG 对话框，用打字机说出三句欢迎词。星空粒子做背景。

## 区块安排（data-nm-id）
| 区块 | 内容 | 为什么 |
| --- | --- | --- |
| `hero` | HUD + 角色卡 + 年资条 + 对话框 | 老成员的身份一眼可见 |
| `ask-me` | 任务板：三个“可以来问我”的任务，点开（`<details>`）看答案和“奖励” | 老成员的接话点是“可以来问我 X”，做成任务最自然 |
| `side-quest` | 支线任务：一起做一款桌游，四个队伍空位 | 老成员“想尝试的事” |
| `inventory` | 背包：社团之外的三个爱好，点物品看说明 | 社团之外的爱好 |
| `achievement` | 隐藏成就：点“解锁”撒花，揭晓让人记住的细节 | 把最好玩的细节留成彩蛋 |

## 用到的 Kit
`nm-theme-night`、`canvas.nm-particles[data-nm-particles=stars]`、`data-nm-typewriter`、`nm-meter--blocks`、`nm-blink`、`data-nm-confetti`、`nm-reveal` + `data-nm-stagger`。像素描边是页面自己写的 `box-shadow` 技巧（四条边各一条阴影，角上留缺口）。字体：得意黑 400（游戏标题感）+ Noto Sans SC 500（正文），HUD 用 JetBrains Mono 800。

## 动效（lively）
星空粒子、打字机、闪烁的 ▼、撒花都尊重减少动效：粒子只画一帧，打字机显示第一句，撒花不触发。

## 借鉴时注意
- **不要编“属性数值”**：RPG 风格很容易诱导写“耐心 99、智力 85”这种假数字。这里唯一的数值条是年资（3/4 年），来自真实年级。
- 任务答案要用主人自己的说法；“奖励”一行可以俏皮，但不能承诺做不到的事。
- `<details>` 原生可折叠、键盘可用，不需要脚本。
