# 设计思路：hackathon-poster（瑞士招募海报）

> 虚构人物：苏晴，大二工业设计，做产品和交互设计，在黑客松找一位后端和一位懂 AI 的开发。人物、学校、项目、数字均为虚构。

## 想给人的感觉
像贴在走廊里的一张组队启事：**大、直接、不啰嗦**。设计师的页面不需要花哨，靠排版本身就能说明“我会设计”。

## 核心视觉
首屏两个竖排的超大汉字 **“后 / 端”**（Noto Sans SC 900，150px）加一个信号橙句号，旁边一个橙色大圆，圆里写“我是苏晴 · 产品 + 交互设计”。封面上“想找什么人”和“我是什么角色”都在第一眼的位置。

## 区块安排（data-nm-id）
| 区块 | 内容 | 为什么 |
| --- | --- | --- |
| `hero` | 启事编号、WANTED、“找一位后端。”、“+ 一位懂 AI 的开发”、我是 / 学校 / 能做 三行表 | 海报式首屏，信息密度高但层级清楚 |
| `can-do` | 01 我能做的：A/B/C 三条，每条一句解释 | 说清楚“我来了能干什么” |
| `project` | 02 做过的：课程项目 + 两个大数字 + 横滑的三步过程卡（访谈→原型→测试，SVG 线框示意） | 设计师要展示过程，不只是结果 |
| `idea` | 03 想做的：“上课录音 → 复习卡片”超大字 + 一段原话 | 黑客松要讲清方向 |
| `match` | 04 你是我要找的人吗：点选技能标签，进度条和结论随之变化 | 让访客自己判断“是不是我”，把接话变成互动 |
| `tabs` | 05 撕一张走：街头小广告式的撕条，点一下就“撕走” | 海报语境里最自然的“来联系我” |

## 用到的 Kit
`nm-theme-mono`（换成暖白底）、`nm-scroll-x`、`nm-chip`（`aria-pressed` 可切换）、`nm-meter`、`nm-vertical`、`nm-reveal`。字体：Inter 400/900（数字与西文）+ Noto Sans SC 400/900，`--nm-display-weight: 900`。

## 动效（calm）
只有滚动渐显和两个由点击触发的小变化（撕条掉落、进度条变长），都是 CSS 过渡，减少动效时直接切换状态。

## 借鉴时注意
- 网格、粗细线、编号区块、一个强调色（信号橙）是这套风格的骨架；颜色超过两种就不像瑞士海报了。
- 匹配小测的结论文字都写在 HTML 里，脚本只负责切换显示，所以不需要额外字符（`extraChars`）。
- 匹配结论不能夸大（不要写“匹配度 98%”这种编出来的数字），进度条只表示“你点了几个”。
