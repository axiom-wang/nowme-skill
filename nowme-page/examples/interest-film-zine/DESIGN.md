# 设计思路：interest-film-zine（胶片手账小志）

> 虚构人物：栗子（昵称），拍了两年胶片，总在凌晨四点去菜市场拍摊主的手。人物为虚构；页面里的“照片”是用 Canvas 画的示意图，真实页面应换成主人自己的照片。

## 想给人的感觉
翻开一本自己装订的小志（zine）：牛皮纸、颗粒、拍立得、纸胶带、红色时间戳。安静、慢、有温度。

## 核心视觉
首屏左侧竖排的大标题 **“凌晨四点的手”**（“四点”用印章红），右侧一张贴着胶带的拍立得，右上角压着一个 “04:12 AM” 印章。brief 里最有意思的那个细节直接成了页面标题。

## 区块安排（data-nm-id）
| 区块 | 内容 | 为什么 |
| --- | --- | --- |
| `hero` | 刊头 + 竖排标题 + 拍立得 + 时间印章 + 一句自我介绍 | 细节做标题，作品做主角 |
| `works` | 印样：一条可以横滑的胶片，六格，每格有片边字码和“××的手” | 作品墙；胶片条比九宫格更像“拍胶片的人” |
| `story` | 为什么是手：点拍立得翻到背面，看到当时写在背面的字 | 主人的原话藏在照片背面，翻面这个动作本身就有意思 |
| `gear` | 一张冲洗店小票：相机、胶卷、冲扫、起床时间 | 同好最爱问的“用什么拍”，用小票写出来不像清单 |
| `together` | 黄色便利贴 + “新手也行”贴纸 | 想一起做的事 |

## 用到的 Kit
`nm-theme-paper`（换成牛皮纸色）、`nm-grain`、`nm-polaroid`、`nm-tape`、`nm-stamp`、`nm-flip` + `data-nm-flip`、`nm-scroll-x`、`nm-note`、`nm-sticker`、`nm-reveal`、`nowme.rng`（让每次画出来的示意照片都一样，封面截图稳定）。字体：霞鹜文楷 400（正文、手写感）+ Noto Serif SC 900（标题），西文用 Instrument Serif 与 JetBrains Mono；中文字体正好 2 款。

## 动效（calm）
只有渐显和点击翻面；Canvas 只画一次，没有动画循环，所以不需要减少动效的分支。

## 借鉴时注意
- 照片一定用主人的（放 `assets/`，`<img src="assets/xxx.jpg">`）；示意图只适合示例页。
- 胶片片边字码（KODAK GOLD 200、帧号）只在主人真用这款胶卷时写。
- 小票里的每一行都要来自采访，不要为了凑格式编出“价格”。
