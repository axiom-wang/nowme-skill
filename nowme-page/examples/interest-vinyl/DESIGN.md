# 设计思路：interest-vinyl（七十年代唱片店）

> 虚构人物：阿岚（昵称，不显示学校），入坑黑胶两年多，只淘有前主人痕迹的二手唱片。人物与故事均为虚构；唱片是真实存在的作品，但封套图是用 SVG 画的抽象图形，没有复制任何真实封面。

## 想给人的感觉
走进一家暖色调的二手唱片店：奶油色的墙、旧条纹、唱机在转。同好一眼就能认出“同类”。

## 核心视觉
首屏正中一张**正在旋转的黑胶**（CSS 渐变画的纹路与反光 + SVG 唱臂），下面是正在播放的唱片名。兴趣社群的规则是“爱好是视觉主角、个人信息靠后”，所以首屏没有自我介绍，只有唱片和一句个人角度：“只淘有前主人痕迹的二手黑胶”。

## 区块安排（data-nm-id）
| 区块 | 内容 | 为什么 |
| --- | --- | --- |
| `hero` | 七十年代四色条纹 + NOW PLAYING + 旋转唱片 + 曲名 + 个人角度 | 爱好本身做主角 |
| `collection` | 横滑的唱片箱，点一张封套 → 唱片标签换色、曲名换掉、下方出现“前主人的痕迹”卡 | 把“个人角度”变成可以玩的东西 |
| `guide` | 入坑指南三张票根 | 接住“新手也欢迎”，也是接话点 |
| `together` | 一张蓝绿色大票：“周末一起逛二手唱片店” | 想一起做的事，放在显眼的位置 |
| `about` | 关于阿岚：入坑故事 + 一句原话 + 流派跑马灯 | 个人信息放最后 |

## 用到的 Kit
`nm-theme-sunset`、`nm-spin`（唱片旋转）、`nm-scroll-x`、`nm-ticket`、`nm-quote`、`nm-marquee`、`nm-reveal` + `data-nm-stagger`、`nm-grain`。字体：Instrument Serif（西文标题）+ Noto Serif SC 400/900。

## 动效（medium）
唱片旋转、跑马灯、渐显都由 Kit 处理，减少动效时唱片静止。点击换唱片只是切换内容，没有脚本动画。

## 借鉴时注意
- 脚本从封套按钮的 `data-title` / `data-meta` 读出文字显示在首屏。**这些文字不在页面的静态文本里时，要手动写进 `manifest.extraChars`**（本例已写），否则字体子集里没有这些字。
- 兴趣页的“作品墙 / 收藏”最好用主人自己的照片（放 `assets/`）。没有照片时，用和爱好气质一致的抽象图形，而不是去找网图。
- 唱片的私人故事（铅笔日期、电影票）是这页最打动人的地方——采访时要追问到这种细节。
