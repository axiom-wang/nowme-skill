# 设计原则（第 4 步）

## 先写设计构想

动手之前写一段话（4–6 句），回答：

1. **感觉**：别人打开这页的第一秒，应该觉得这个人是什么样的？（不是“简洁大方”，而是“像走进一家暖色的二手唱片店”）
2. **核心视觉**：一个视觉主角，通常来自 brief 的“重点细节”——旋转的唱片、竖排的“凌晨四点的手”、一张招募 issue 卡。
3. **区块**：按顺序列出 `data-nm-id` 和每块放什么。
4. **Kit 与动效**：用哪些组件、哪种主题与字体、动效档位。

## 按场景

| | 黑客松 / 创业营 | 兴趣社群 | 社团招新 |
| --- | --- | --- | --- |
| 首屏（封面）必须有 | 角色 + 想找什么样的队友（+ 1–3 个技能） | 爱好本身：作品、收藏、现场 | 这个人：名字 + 一个让人记住的细节 |
| 信息密度 | 可以高，扫一眼能判断“要不要来聊” | 作品为主、文字为辅，个人信息靠后 | 少而有趣，可以点着玩 |
| 建议区块 | 项目展示、能力标签、组队需求、这次想做的 | 收藏、作品墙、入坑指南、想一起做的事 | 自我介绍、想尝试的事、可以来问我、社团之外 |
| 视觉基调（只是建议） | 利落、科技感 | 跟着兴趣的气质走 | 活泼、个人化 |
| 示例 | `hackathon-terminal`、`hackathon-poster` | `interest-vinyl`、`interest-film-zine` | `club-newbie-sticker`、`club-senior-quest` |

同一个人在不同墙上：从画像里**挑出一部分、换一种讲法**，而不是同一份内容换皮肤。主人说明了本页意图时，以主人为准。

## 让人眼前一亮

- **一个细节做主角**：把 brief 里最具体、最别人没有的那个细节放大成标题、主视觉或互动（“会五种方言说你吃了没”→ 点一下换一种方言）。
- **结构服务内容**：让形式来自主人的世界——程序员用终端和 diff，设计师用海报网格，拍胶片的用印样和相纸，玩桌游的用任务板。
- **一个让人想点的互动**就够了：翻面、换一个、拖贴纸、选技能看结论。互动要有内容回报（看到原话、细节），不是为了动而动。
- **排版做层级**：大字、粗细对比、留白、对齐；中文大标题用 900 字重或有个性的字体（得意黑、思源宋体 900），正文 15–17px、行高 1.6–1.8。
- **颜色克制**：一个主色 + 一个点缀色；用 Kit 主题打底再微调。

## 避免 AI 模板感

不要：

- 渐变色背景 + 居中大标题 + 三张带 emoji 图标的卡片。
- “热爱生活 / 追求卓越 / 乐于分享”之类谁都能用的话；“欢迎来到我的个人主页”。
- 技能百分比条、星级、“耐心 99”这类编出来的数字。
- 每块都一样的卡片 + 标题 + 段落结构；所有元素都居中。
- 用示例页里的虚构人物、文案、数字。
- 为了填满页面编内容。信息少时，页面就短一点、留白多一点——短而真比长而空好。

要：

- 用主人的原话（放进 `nm-quote` 或直接做标题）。
- 具体的名词：作品名、地名、时间、物件。
- 承认短板也可以很有魅力（“不擅长：配色和排版——所以在找你”），前提是主人这么说过。

## 移动端与封面

- 以 375px 宽设计；在 560px 以上居中，两侧留白。
- 封面是页面顶部 375×500 的截图：首屏最关键的信息必须在这 500px 里，且在静态截图里也看得清（不要依赖动画中途的状态）。
- 触摸目标至少 44px 高；横滑区域要露出下一张的边，让人知道能滑。
- 文字与背景对比要够（深色背景上不要用中灰小字）。

## 动效档位

| 档位 | 建议 |
| --- | --- |
| calm（安静） | 只有滚动渐显和点击后的状态变化 |
| medium（适中） | 再加 1–2 处常驻小动效：打字机、跑马灯、旋转、粒子背景 |
| lively（活泼） | 可以有撒花、漂浮贴纸、拖动、多处循环动效；仍然要保证减少动效时内容完整 |
