# 截图自查清单（第 5 步）

`nowme preview page` 之后，打开它打印出的截图（都在工作目录的 `.nowme-preview/` 里：封面 `cover.png`、整页 `full.png`、减少动态效果的整页 `full-reduced-motion.png`、按区块切开的 `blocks/NN-<data-nm-id>.png`），逐项过一遍。每一项不满足就改，改完重新 `validate` + `preview`，至少做一轮。

## 封面（页面顶部 375×500）

- [ ] 封面上一眼能看出场景要求的东西：黑客松 = 角色 + 想找的人；兴趣社群 = 爱好本身；社团 = 这个人 + 一个细节。
- [ ] 封面在墙上缩小显示时（大约一半大小）主标题仍然清楚。
- [ ] 封面没有截到半截的文字、动画中途的空白、还没出现的内容。

## 层次与可读性

- [ ] 只有一个视觉主角，视线从它开始往下走。
- [ ] 标题、正文、注释三级字号分得清；正文不小于 14px。
- [ ] 文字和背景对比足够；深色背景上没有灰色小字。
- [ ] 留白均匀，没有挤成一团或空出大洞；左右边距一致。
- [ ] 中文字体真的生效了（预览里看起来不是系统默认字体），标题没有伪粗体。

## 像不像这个人

- [ ] 页面上每一句话都能在 brief 里找到出处；没有编的经历、数字、引语。
- [ ] 至少用上了 1 个“重点细节”，并且它是视觉重点，而不是埋在段落里。
- [ ] 主人的原话原样出现了（如果 brief 里有）。
- [ ] 边界都守住了：不该显示的学校 / 真名 / 照片没有出现；页面里没有联系方式。
- [ ] 去掉名字之后，这一页仍然不能原样套给另一个人。

## 场景与墙

- [ ] 符合这面墙的场景目标（`pageGoal`）和组织者的一句话。
- [ ] 接话点（`card.json`）具体、能接话，和页面内容对得上。
- [ ] 页面里引导访客用平台的“想聊这个”，而不是自己留联系方式。

## AI 模板感

- [ ] 没有“渐变背景 + 居中标题 + 三张 emoji 卡片”的套路。
- [ ] 没有空话（热爱生活、追求卓越……）、没有编出来的技能百分比。
- [ ] 不是示例页换了文字：结构、视觉主角、互动是为这个人选的。

## 技术

- [ ] `nowme validate` 0 错误；警告都看过。
- [ ] `nowme preview` 没有渲染错误（脚本异常、CSP 违规），加载不慢；字体子集里没有“字体本身没有”的字。
- [ ] 打开“减少动态效果”（`prefers-reduced-motion`）时内容完整、没有卡在隐藏状态（看 `full-reduced-motion.png`）。
- [ ] 互动元素可以点、键盘可以操作；外链都用 `data-nm-href` 且是 https。
- [ ] 横滑、拖动在手机宽度下不妨碍上下滚动。
